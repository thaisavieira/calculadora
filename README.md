# Calculadora em Go
Este é meu primeiro projeto desenvolvido utilizando a linguagem Go. O objetivo foi dar os primeiros passos na linguagem por meio da criação de uma calculadora simples executada pelo terminal. 
O programa permite ao usuário escolher uma operação matemática e informar dois valores para realizar o cálculo.

## Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão

## Tecnologias

* Go

## Como executar

Clone o repositório:

```bash
git clone https://github.com/thaisavieira/calculadora.git
```

Entre na pasta do projeto:

```bash
cd calculadora
```

Execute o programa:

```bash
go run main.go
```
